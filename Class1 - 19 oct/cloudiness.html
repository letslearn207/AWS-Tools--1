Turning point

Virtualization

Traditionally one physical server ran one application, so hardware sat underused. Virtualization lets multiple isolated virtual instances share one physical machine.

Hypervisor

Software that creates and manages VMs. Allocates CPU, memory and storage, isolates workloads, and manages communication between VMs and hardware.

Virtual machine

A software-based computer with its own OS, running independently while sharing the same physical hardware on top of a hypervisor.

Cloud providers carve powerful physical servers into many VMs, which is the technical foundation of cloud.

Introduction

Cloud = renting instead of owning

Servers, storage, databases, networking and software platforms, provisioned on demand, paid only for what you use. Like drawing electricity from a grid instead of running a private generator.

Then

Buy hardware → install OS → maintain and upgrade everything manually.

Now

Provision in minutes → provider handles maintenance → teams focus on apps and users.

Edge & CDN

Why is video still slow for some users?

A CDN caches copies of images, videos and static files in edge locations so content is served from the nearest one (Amazon CloudFront on AWS). Click a city to watch a request travel.

Pick a city. The first request misses the cache and travels to the Mumbai region; the next is served from the edge.

Edge locations ≠ Regions ≠ Availability Zones.

Edge computing

Processing data close to where it is generated instead of sending everything to a far-away cloud data center. Use it when speed matters, decisions must be instant, or bandwidth is limited.

🚗 Autonomous vehicles

Cars must react in milliseconds. Decisions are made inside the vehicle.

Edge: ~2 ms

🏭 Factory IoT sensors

Sensors detect temperature or pressure; immediate alerts prevent damage by processing in the factory network. Less latency, less bandwidth.
